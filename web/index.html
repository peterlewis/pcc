PCC BRIDGE · pccd MACOS + LINUX
A small daemon that owns the clock's serial port once and shares it: this app connects through it from any browser (no port contention, no picker), and chrony gets the clock's PPS — your machine becomes a stratum-1 time source. When pccd is running, CONNECT DEVICE uses it automatically.
DOWNLOAD — macOS (UNIVERSAL)
curl -L -o pccd https://github.com/peterlewis/pcc/releases/latest/download/pccd-macos-universal && chmod +x pccd
DOWNLOAD — LINUX (STATIC · x86_64 / aarch64)
curl -L -o pccd https://github.com/peterlewis/pcc/releases/latest/download/pccd-linux-$(uname -m) && chmod +x pccd
Run ./pccd with the clock plugged in — this page detects it within seconds. Checksums and source: github.com/peterlewis/pcc/releases, or build from host/pccd (make — no dependencies).
OPTIONAL — FEED CHRONY (STRATUM-1 NTP)
# /etc/chrony/chrony.conf (Linux) · /opt/homebrew/etc/chrony.conf (macOS brew) refclock SOCK /var/run/chrony.pcc.sock refid PCC precision 1e-4
Start chronyd first (it creates the socket), then ./pccd -s /var/run/chrony.pcc.sock. On Linux use precision 1e-2 — PPS lands via arrival timestamps (~ms) there; macOS uses the USB frame clock (~0.1 ms). Verify with chronyc sources -v.
