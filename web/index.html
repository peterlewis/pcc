Connect

Pair the browser with the clock over USB. Click Connect and pick the clock's serial port in the browser prompt.

Your browser doesn't support Web Serial. Open this page in Chrome, Edge, Arc, Brave, or Opera on a desktop OS.

Serial port

The Mk IV enumerates as a cu.usbmodem* device on macOS and a COM port on Windows. If this is your first connect, the browser will ask which port to grant access to — pick the one that appears when you plug the clock in.

Built on

Web Serial API · HTML5 Canvas · three.js / globe.gl (offline, MIT) · no backend, no account, no tracking. The whole page is static files from a CDN.

About PCC Web

A browser-based subset of the native macOS PCC companion.

What's here

  • Connect over Web Serial (Chromium browsers only)
  • Drive display modes, text, countdowns, brightness
  • Live polar sky view with SNR-coloured satellites
  • GPS fix info, Maidenhead grid, solar & lunar position
  • Raw serial monitor with custom command input

What's not here

  • NTP time server — browsers can't open UDP sockets or listen on a port. Stays in the Mac app.
  • Firmware / timezone updates — need USB mass-storage mount, which the browser can't do. Stays in the Mac app.
  • WeatherKit — Apple-only. A generic weather provider would be a swap-in.
  • On-device AI insights — Apple's Foundation Models are Mac-only; a BYO-key LLM call would be a swap-in.
  • 3D globe + long-term trail history — coming in a follow-up (globe.gl is already bundled; IndexedDB-backed SatPass store is the next port).

Browser support

Web Serial ships in Chromium-based browsers — Chrome, Edge, Arc, Brave, Opera — on desktop OSes. Safari and Firefox don't implement it, and there's no public roadmap for them to do so. HTTPS is required for non-localhost hosting; GitHub Pages, Cloudflare Pages, and Netlify all provide that out of the box.
